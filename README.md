## About me

I build scalable software from zero to fully deployed products: architecture, backend systems, AI features, web and mobile interfaces, testing, and infrastructure. I use Python, and I focus on applied AI—RAG, embeddings, vector search, AI agents, and agentic systems that solve real problems. I use agentic development tools to move from idea to working product quickly while staying responsible for the architecture, correctness, and quality. I'm a tech and startup enthusiast who enjoys building.
